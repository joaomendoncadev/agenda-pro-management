# Changelog

## 2.2.0

- Corrigidos erros de compilação TypeScript no frontend.
- Corrigido uso de ícone não exportado pelo lucide-react.
- Adicionado Error Boundary para evitar tela branca sem diagnóstico.
- Adicionados `.nvmrc`, `npm run clean` e `npm run dev:host`.

## 2.1.0

- Agenda premium, indicadores, perfil analítico de clientes, comandas e caixa.

## 2.3.0
- Agenda por profissional, bloqueios visuais, drag-and-drop entre profissionais e desfazer movimentação.

## [2.4.0]
- Novo módulo de estoque e produtos.
- Movimentações de entrada, saída e ajuste com proteção contra saldo negativo.
- Alertas de estoque mínimo e valor financeiro armazenado.
- Gestão de comissões por profissional e período.
- Pagamento de comissão integrado ao módulo financeiro.
